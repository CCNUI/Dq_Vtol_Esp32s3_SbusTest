## ESP32-S3 SBUS 按钮测试程序 (中文)

这是一个为 ESP32-S3 (Arduino 框架) 提供的 **单通道 (CH1)** SBUS 输出（发射）测试工具。它专为 ESP32-S3-DevKitC 开发板设计，使用 **BOOT 键 (GPIO 0)** 来控制 CH1 的输出。

它使用硬件 UART (Serial1) 在 **GPIO 14** 上生成符合 SBUS 协议（100,000 波特率, 8E2, 反向逻辑）的信号，同时保持 CH2-16 在 1500us 中位。

此工具的主要功能是使用物理按键快速测试连接到 SBUS 总线上 CH1 的舵机或其他设备。

-----

### 功能

&nbsp; * **CH1 专注测试**：CH1 可在 1000µs - 2000µs 之间通过按键控制，所有其他通道 (CH2-16) 恒定为 1500µs。
&nbsp; * **50Hz 刷新率**：以 20ms 的间隔同步更新所有通道。
&nbsp; * **标准 SBUS 协议**：100,000 波特率, 8E2 格式, 反向串行逻辑 (GPIO 14)。
&nbsp; * **按键控制 (GPIO 0)**：使用板载 "BOOT" 键切换模式和 PWM 值。
&nbsp; * **双模式控制**：
&nbsp;   1.  **手动步进模式 (默认)**：开机默认为 1500µs。短按 BOOT 键可在 (1000, 1250, 1500, 1750, 2000µs) 之间循环切换。
&nbsp;   2.  **自动扫描模式**：长按 BOOT 键 (1秒) 切换到 CH1 1000-2000µs 自动扫描。再次长按可退出扫描，并返回 1500µs。
&nbsp; * **状态指示灯 (GPIO 48)**：
&nbsp;     * **颜色 (Hue)**：代表 CH1 的 PWM 值。从 1000µs (红色) 渐变到 1500µs (黄色) 再到 2000µs (绿色)。

### 硬件要求

&nbsp; * **ESP32-S3 开发板** (示例基于 ESP32-S3-DevKitC)
&nbsp; * **SBUS 接收设备** (如舵机、飞控或 SBUS 解码器)

### 软件依赖 (Arduino IDE)

1.  **ESP32 Arduino 核心**：确保已在“开发板管理器”中安装了 `esp32` 支持 (v2.0.x 或更高版本)。
2.  **Adafruit NeoPixel**：用于控制板载 RGB LED。请通过“库管理器”安装。

### 硬件连接

ESP32-S3 (IO14) -----> SBUS 信号线 (RX) ESP32-S3 (GND) -----> SBUS 地线 (GND)


**重要**：SBUS 是反向逻辑。大多数飞控 (FC) 或 SBUS 舵机的 `SBUS` 端口已经内置了反向器。

### 如何使用（测试流程）

1.  上传代码到你的 ESP32-S3。
2.  (可选) 打开 Arduino **串口监视器** (Serial Monitor)，波特率 **115200**，以查看当前模式和 PWM 值的提示信息。
3.  开发板上的 "RST" 键是复位键，**"BOOT" 键 (GPIO 0) 是我们的控制键**。

#### 1. 默认状态 (手动步进)

&nbsp; * 程序启动后，CH1 默认为 **1500µs** (中立位)。
&nbsp; * 板载 LED 将显示**黄色**。

#### 2. 短按 (切换 PWM 步进值)

&nbsp; * **短按** (按下并释放) 一次 "BOOT" 键。
&nbsp; * CH1 输出将切换到 **1000µs**。LED 将变为**红色**。
&nbsp; * 再次**短按**，CH1 将切换到 **1250µs**。
&nbsp; * 再次**短按**，CH1 将切换到 **1500µs** (黄色)。
&nbsp; * 再次**短按**，CH1 将切换到 **1750µs**。
&nbsp; * 再次**短按**，CH1 将切换到 **2000µs** (绿色)。
&nbsp. * 再次**短按**，CH1 将循环回到 **1000µs** (红色)。

#### 3. 长按 (切换扫描模式)

&nbsp; * 在任何时候，**长按 "BOOT" 键 1 秒钟**。
&nbsp; * 程序将切换到**自动扫描模式**。
&nbsp; * CH1 的 PWM 值将开始在 1000µs 和 2000µs 之间来回扫描。
&nbsp; * LED 颜色将随 PWM 值在**红-黄-绿**之间平滑渐变。

#### 4. 退出扫描模式

&nbsp; * 当处于**自动扫描模式**时，再次**长按 "BOOT" 键 1 秒钟**。
&nbsp; * 程序将**退出扫描**，并重置回**手动步进模式**。
&nbsp; * CH1 将返回到 **1500µs** (中立位)，LED 变为**黄色**。
